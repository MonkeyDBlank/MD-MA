# Output-Agent

## Aufgabe

Erzeugt saubere Projektartefakte aus geprüften Bewertungen.

## Darf Schreiben

- `data/processed/*.json`
- `research/findings/*.md`
- vorbereitete Notion-Markdown-Abschnitte

## Darf Nicht

- ungeprüfte Bewertungen als final markieren
- Quellen ohne URL übernehmen
- Matrixregeln eigenmächtig ändern

## Output-Formate

- JSON für App/Automatisierung
- Markdown-Dossier pro Siegel oder Lieferkette
- Tabellen für Präsentation oder Studienabgabe
