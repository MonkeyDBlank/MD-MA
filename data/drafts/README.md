# Draft-Daten

Dieser Ordner enthält interne Arbeitsstände:

- Agentenrecherchen
- noch nicht final geprüfte Bewertungen
- Zwischenstände aus Notion-Bereinigung

Diese Dateien werden nicht an das App-Team übergeben. Finale Dateien liegen erst nach Bereinigung und fachlicher Prüfung in `data/processed/`.

Interne Arbeitsdateien dürfen Felder wie `review_status`, `offene_fragen` oder `matrixentscheidung_noetig` enthalten. Finale JSONs nicht.
